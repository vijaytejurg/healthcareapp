# 🚪 HOW TO LOGOUT

## Simple Steps to Logout:

### **Method 1: From Profile Screen (Recommended)**
1. **Navigate to Profile:**
   - If you're a **Patient**: Click the "Profile" tab at the bottom
   - If you're a **Doctor/Other Role**: Navigate to Profile from your home screen

2. **Find Logout Button:**
   - Scroll down in the Profile screen
   - Look for the red "Logout" button (with logout icon)
   - It's below the "Book Consultation" button

3. **Click Logout:**
   - Click the "Logout" button
   - A confirmation alert will appear
   - Click "Logout" to confirm
   - You'll be automatically redirected to Login screen

---

## ✅ What Happens When You Logout:

1. ✅ Firebase Auth signs you out
2. ✅ User data is cleared
3. ✅ App automatically redirects to Login screen
4. ✅ You'll need to login again to access the app

---

## 🔍 If Logout Button is Not Visible:

1. **Scroll down** in Profile screen - it's at the bottom
2. **Check you're on Profile tab** (not another screen)
3. **Refresh the app** if needed

---

## 🛠️ Troubleshooting:

### **Logout Not Working?**
- Check browser console (F12) for errors
- Make sure you're connected to internet
- Try refreshing the page

### **Still Logged In After Logout?**
- Clear browser cache
- Hard refresh (Ctrl+Shift+R)
- Check Firebase Auth state

---

**That's it! Logout is simple and works automatically!** 🎉
